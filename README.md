# Mowojang Discord Bot

Look up Minecraft profiles, sessions, and API status right from Discord.

[Click here to add the Bot as a Discord Application](https://discord.com/oauth2/authorize?client_id=1508890289849368606)

## Commands

| Command             | Description                                      |
| ------------------- | ------------------------------------------------ |
| `/profile <player>` | Look up a Minecraft profile by username or UUID. |
| `/session <player>` | View a session profile, including skin and cape. |
| `/uuid <username>`  | Convert a username to a UUID.                    |
| `/username <uuid>`  | Convert a UUID to a username.                    |
| `/status`           | Check Mowojang and related Minecraft API status. |
| `/stats`            | View bot command statistics.                     |
